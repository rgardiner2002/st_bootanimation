# Ford ST Boot Animation – 2400×900

Custom Ford ST / Ford Performance boot animation designed for Android-based car head units.

## Details

- **Resolution:** 2400×900
- **Duration:** ~5 seconds
- **Frame Rate:** 30 FPS
- **Format:** Android `bootanimation.zip`
- **Playback:** Once per startup
- **Original Video:** 3840×1440 @ 60 FPS
- **Designed for:** 2400×900 Android head units

## Installation

Installation methods vary depending on your Android head unit and firmware.

For compatible units:

1. Download `bootanimation.zip`.
2. Transfer the file to your head unit using USB, SD card, or by downloading it directly on the unit.
3. Open your head unit's **Boot Animation** or **Factory Settings** menu.
4. Import or select the custom boot animation.
5. Restart the head unit to test it.

> **Note:** Do not extract `bootanimation.zip` unless your particular head unit requires you to do so.

## Compatibility

This animation was created for a **2400×900** display.

It was originally prepared for a **TS10 / UIS7862-based Android head unit**, but it may work with other Android head units that support standard Android boot animations at this resolution.

Compatibility is not guaranteed across every firmware or manufacturer.
